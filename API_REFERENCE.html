📚 Agent Pilot API Reference ​

Complete specification of message passing actions, data schemas, and the global runtime API of Agent Pilot.

1. Messages Sent to Background Service Worker ​

Dispatched via chrome.runtime.sendMessage({ action: "...", ... }):

1.1 Tab Management & Navigation ​

ActionRequired ParametersResponseDescription
get_active_tabNone{ tab: TabObject }Get active tab details
list_tabsNone{ tabs: TabObject[] }List all open tabs
new_taburl?: string{ success: true, tab }Open new tab with target URL
navigatetabId: number, url: string{ success: true, tab }Navigate tab to new URL
reload_tabtabId: number{ success: true }Reload target tab
close_tabtabId: number{ success: true }Close target tab

1.2 Chrome DevTools Protocol (CDP) ​

ActionRequired ParametersResponseDescription
attach_debuggertabId: number{ success: boolean, error?: string }Attach CDP and enable Console, Network, and Performance domains
detach_debuggertabId: number{ success: true }Detach CDP from tab
get_debugger_statustabId: number{ attached: boolean }Inspect current CDP connection state
get_devtools_datatabId: number{ console: [], network: [], attached }Retrieve buffered console logs and network requests
clear_consoletabId: number{ success: true }Clear console buffer
clear_networktabId: number{ success: true }Clear network request history
get_performance_metricstabId: number{ success: boolean, metrics: Object }Retrieve JS Heap, DOM Node counts, Layout metrics

1.3 Screenshot Capture ​

ActionRequired ParametersResponseDescription
capture_screenshotmode: "visible"{ success: true, dataUrl: string }Capture full visible viewport
capture_screenshotmode: "element" | "region", tabId, clip: {x, y, width, height}{ success: true, dataUrl, requiresCrop?: boolean, clip }Capture and crop to bounding rectangle

Synthetic DOM events cannot pierce cross-origin iframes or interact with <canvas> / WebGL games.
memory.heapSnapshot dumps V8 heap snapshots to .heapsnapshot files; use MCP tool browser_analyze_heapsnapshot to inspect retainers or compare snapshots.

4. Global API Object window.__AGENT_PILOT__ ​

Available in the webpage context for programmatic automation:

⚠️ Error Semantics: Methods returning a Promise reject with an Error on failure (previously resolved null). Only timeouts resolve null.

typescript
interface AgentPilotBridge {
  version: string;
  moveMouse(x: number, y: number, duration?: number): Promise<{ x: number, y: number }>;
  click(x?: number, y?: number): Promise<{ success: boolean, element: any }>;
  animateClick(x: number, y: number, selector?: string): Promise<any>;
  type(selector: string | null, text: string, clear?: boolean): Promise<{ success: boolean, textEntered?: string }>;
  scroll(deltaX?: number, deltaY?: number): Promise<{ success: boolean, scrollX: number, scrollY: number }>;
  hover(selector: string): Promise<any>;
  drag(from: string | { x: number, y: number }, to: string | { x: number, y: number }, steps?: number): Promise<any>;
  pressKey(key: string, selector?: string): Promise<any>;
  waitFor(options: any): Promise<any>;
  snapshot(maxElements?: number, format?: string): Promise<any>;
  fillForm(fields: any, submitSelector?: string, pressEnter?: boolean): Promise<any>;
  toggleInspector(enabled: boolean): Promise<{ success: boolean, active: boolean }>;
  isInspectorActive(): Promise<{ active: boolean }>;
  getElement(selector: string, includeStyles?: boolean): Promise<ElementDetails | null>;
  startElementSnap(): Promise<{ success: boolean }>;
  stopElementSnap(): Promise<{ success: boolean }>;
  isElementSnapActive(): Promise<boolean>;
  startRegionCrop(): Promise<{ success: boolean }>;
  getLockedElement(): Promise<ElementDetails | null>;
  pickColor(x?: number, y?: number): Promise<{ success: boolean, color: { hex: string, rgb: string, rgba: string, hsl: string, oklch: string } | null }>;

  isEyedropperActive(): Promise<{ active: boolean }>;

  // Agent interaction state

  isAgentTab(): Promise<boolean>;

  isFeedbackStudioActive(): Promise<boolean>;
  getFeedbackItems(): Promise<FeedbackItem[]>;

  clearFeedbackItems(): Promise<{ success: boolean }>;
  copyFeedbackPrompt(): Promise<any>;

}

5. Model Context Protocol (MCP) Tool Catalog (68 Tools) ​

Agent Pilot exports 68 Model Context Protocol (MCP) tool schemas via stdio (agent-pilot mcp) and the schema directory (mcp/agent-pilot/). All tools map directly to bridge RPC commands:

DomainTools (Count)Description
Navigation & Tabsbrowser_open_tab, browser_close_tab, browser_list_tabs, browser_navigate (4)Lifecycle management of Chrome tabs inside the 🤖 Agent Pilot tab group.
Instance & Sessionbrowser_list_instances, browser_select_instance, browser_start_session, browser_end_session, browser_set_busy (5)Multi-browser discovery, instance routing, persistent neon cursor session, and user lock shield.
Page Interactionbrowser_click, browser_type, browser_scroll, browser_hover, browser_drag, browser_press_key, browser_fill_form, browser_upload_file, browser_handle_dialog (9)Mouse and keyboard automation (synthetic DOM or trusted CDP via via: "cdp"), file uploads, and JavaScript dialogs.
Observation & Inspectionbrowser_snapshot, browser_screenshot, browser_get_element, browser_evaluate, browser_wait_for, browser_pick_color (6)DOM/accessibility snapshots, hardware-accelerated screenshots with annotations/spotlight, element geometry, JS execution, and color eyedropper.
Batch Automationbrowser_run_actions (1)Atomic multi-step action pipeline executing multiple actions in one round-trip (saving 80%+ tokens and latency).
Feedback Studiobrowser_get_pending_feedback, browser_wait_for_feedback (2)3-Channel visual UI feedback: retrieve inbox feedback sessions or reactive long-polling.
Emulation & Contextsbrowser_emulate, browser_resize_page, browser_create_context, browser_list_contexts, browser_close_context (5)Device/viewport emulation and isolated multi-tenant browser contexts (negative tab IDs).
DevTools & Networkbrowser_devtools_status, browser_get_devtools_data, browser_list_network_requests, browser_get_network_request, browser_get_css_styles (5)CDP connection health, console/network stream buffers, HTTP response bodies, and computed/cascade CSS inspection.
Performance & Auditbrowser_performance_metrics, browser_performance_trace, browser_performance_analyze_insight, browser_lighthouse_audit, browser_lighthouse_analyze_audit, browser_accessibility_snapshot (6)Core Web Vitals, timeline traces, trace insight analysis, Lighthouse performance/SEO audits, and full accessibility tree.
Memory & Heapbrowser_heap_capability, browser_take_heapsnapshot, browser_analyze_heapsnapshot (3)HeapProfiler capability probing, V8 heap snapshots, retainer queries, and constructor diffing.
Screencast & Workersbrowser_screencast_start, browser_screencast_stop, browser_service_workers (3)Native MP4 screen recording and Service Worker inspection/debugging.
Chrome Recorderbrowser_recorder_start, browser_recorder_stop, browser_recorder_state, browser_recorder_replay, browser_recorder_measure, browser_recorder_export, browser_recorder_import, browser_recorder_edit, browser_recorder_clear (9)Chrome DevTools Recorder flow capture, replay, performance measurement, export/import, and editing.
Extensions & WebAuthnbrowser_manage_extensions, browser_webauthn (2)Chrome extension lifecycle management (install/toggle/reload) and virtual WebAuthn/Passkey credential emulation.
