# 🐞 Báo Lỗi & Đề Xuất Tính Năng

Cảm ơn bạn đã sử dụng **Agent Pilot**. Mọi ý kiến đóng góp hoặc báo cáo lỗi của bạn đều giúp dự án ngày càng hoàn thiện hơn cho cộng đồng.

---

## 🐞 Báo Cáo Lỗi (Report Bugs) & Đề Xuất Tính Năng

Nếu trong quá trình sử dụng bạn gặp lỗi kết nối, trình duyệt thao tác chưa chuẩn xác, hoặc gặp vấn đề tương thích với một công cụ AI cụ thể, hãy gửi thông báo để khắc phục kịp thời.

### Kênh Tiếp Nhận Chính Thức
- **Báo cáo lỗi (Bug Report)**: [Tạo Issue báo lỗi trên GitHub](https://github.com/ducconit/agent-pilot/issues/new)
- **Đề xuất tính năng (Feature Request)**: [Gửi ý tưởng tính năng mới trên GitHub](https://github.com/ducconit/agent-pilot/issues/new)
- **Lỗ hổng bảo mật (Security)**: Vui lòng xem hướng dẫn tại [Chính Sách Bảo Mật (SECURITY.md)](https://github.com/ducconit/agent-pilot/blob/main/SECURITY.md) trước khi công bố các lỗ hổng nhạy cảm.

### Thông Tin Cần Cung Cấp Khi Báo Lỗi
Để giúp việc tái hiện và xử lý lỗi diễn ra nhanh nhất, bạn vui lòng đính kèm các thông tin sau:

| Hạng mục | Nội dung chi tiết cần mô tả |
| :--- | :--- |
| **Hệ điều hành** | Windows 10/11, macOS (Intel / Apple Silicon) hoặc bản phân phối Linux đang dùng |
| **Phiên bản trình duyệt** | Google Chrome, Chromium, Brave hoặc Edge (ví dụ: Chrome 130+) |
| **Công cụ AI sử dụng** | Claude Code, Cursor, Windsurf, Google Antigravity, Cline, OpenCode... |
| **Phương thức kết nối** | Bạn đang kết nối qua **Skills + CLI** hay qua **MCP Server** |
| **Các bước tái hiện lỗi** | Câu lệnh prompt đã dùng hoặc trình tự các bước dẫn đến lỗi |
| **Hình ảnh / Log minh họa** | Ảnh chụp màn hình hoặc thông báo lỗi (lưu ý che các thông tin cá nhân nếu có) |
