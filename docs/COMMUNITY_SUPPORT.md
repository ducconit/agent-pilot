# 🐞 Report Bugs & Feature Requests

We appreciate your feedback in making **Agent Pilot** a reliable, universal browser controller for the AI developer community.

---

## 🐞 Reporting Bugs & Requesting Features

If you encounter unexpected behavior, browser automation glitches, or compatibility issues with a specific AI coding tool, please let us know so we can resolve it quickly.

### Where to Submit Reports
- **Bug Reports**: [Open a Bug Issue on GitHub](https://github.com/ducconit/agent-pilot/issues/new)
- **Feature Requests**: [Suggest an Enhancement on GitHub](https://github.com/ducconit/agent-pilot/issues/new)
- **Security Vulnerabilities**: Please review our [Security Policy](https://github.com/ducconit/agent-pilot/blob/main/SECURITY.md) before disclosing sensitive vulnerabilities publicly.

### What to Include in a Bug Report
To help us reproduce and diagnose the issue rapidly, please include:

| Information | Details to Provide |
| :--- | :--- |
| **Operating System** | Windows 10/11, macOS (Intel / Apple Silicon), or Linux distribution |
| **Browser Version** | Google Chrome, Chromium, Brave, or Edge version (e.g., Chrome 130+) |
| **AI Agent / Tool** | Claude Code, Cursor, Windsurf, Google Antigravity, Cline, OpenCode, etc. |
| **Integration Mode** | Whether you are using **Skills + CLI** or **MCP Server** |
| **Steps to Reproduce** | The prompt or action sequence that triggered the issue |
| **Visual Evidence** | Screenshots or console error messages (ensure any personal data is masked) |
