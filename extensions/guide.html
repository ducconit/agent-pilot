0. Hướng Dẫn Cài Đặt & Khởi Chạy Nhanh (Installation & Setup)

🧩

Cài Đặt Chrome Extension (MV3)

Tiện ích mở rộng Google Chrome Manifest V3 hiện đại, giao tiếp trực tiếp qua Chrome Side Panel API và Chrome DevTools Protocol:

  • Tải tệp agent-pilot-v1.0.9-beta.zip từ GitHub Releases và giải nén
  • Mở chrome://extensions $\rightarrow$ Gạt bật Developer mode
  • Nhấn Load unpacked và chọn thư mục vừa giải nén
  • Ghim icon 📌 lên thanh công cụ và mở Side Panel (Ctrl+Shift+P hoặc Cmd+Shift+P)
⚡

Standalone Go CLI & MCP Server

Bản nhị phân độc lập viết bằng Golang, tích hợp sẵn Bridge Server 58765, MCP Server stdio và bộ lệnh CLI automation:

  • Không phụ thuộc Node.js hay npm, khởi động <5ms, RAM chỉ ~12MB
  • Hỗ trợ sẵn cho Linux (x64/ARM64), macOS (Intel/M1-M4) và Windows
  • Cài service chạy ngầm tự khởi động 1 lệnh: agent-pilot service install
  • Kiểm tra trạng thái service: agent-pilot service status
🤖

Cấu Hình MCP Cho AI Assistant

Trang bị khả năng điều khiển trình duyệt cho Claude Desktop, Cursor, Google Antigravity, OpenCode qua giao thức stdio:

{ "mcpServers": { "agent-pilot": { "command": "agent-pilot", "args": ["mcp"] } } }
  • Tự động chuyển tiếp Dual Mode: Không xung đột cổng khi chạy nhiều IDE
  • Tự động che giấu 12 mẫu khóa bí mật (API Key, JWT, Bearer) trước khi gửi LLM
📦

Kỹ Năng Agent Skills (skills.sh)

Tương thích 100% chuẩn Agent Skills Open Ecosystem. Tự động tải và cài đặt toàn bộ kỹ năng cho mọi coding agent:

npx skills add https://github.com/ducconit/agent-pilot-extension
  • Áp dụng cho Claude Code, Cursor, Codex, Antigravity, Amp, Roo, Devin
  • Thêm cờ -g --all để cài đặt toàn cục cho mọi trợ lý trên máy tính

1. Tích Hợp AI Agent & Bộ 16 Công Cụ MCP

⚡

Cổng WebSocket & HTTP REST (58765)

Cầu nối vòng lặp nội bộ (Loopback bridge) tốc độ cao, độ trễ cực thấp. Hỗ trợ tự động chuyển đổi Master/Forwarder giúp nhiều AI Agent hoạt động đồng thời mà không xung đột cổng (Zero Port Conflict).

  • Cổng chuẩn: 127.0.0.1:58765 (WebSocket + HTTP API)
  • Độc lập hoàn toàn, không phụ thuộc cloud bên ngoài
  • Bảo mật nội bộ: Chặn các truy vấn cross-origin từ website
curl -X POST http://127.0.0.1:58765/api -d '{"method":"system.ping"}'
📦

Động Cơ Thực Thi Hàng Loạt (Batch Engine)

Công cụ browser_run_actions cho phép AI Agent gửi một chuỗi kịch bản gồm nhiều bước chỉ trong một tool call duy nhất, giúp tiết kiệm hơn 80% token và giảm thời gian chờ phản hồi.

  • Chuỗi hành động: mở tab, điều hướng, cuộn, gõ chữ, click, chụp ảnh
  • Tự động cuộn phần tử vào giữa tầm nhìn trước khi click/gõ
  • Tự động giữ ngữ cảnh tab (tabId) xuyên suốt kịch bản
🔒

Chỉ Báo Tinh Tế & Giám Sát Agent

Khi AI Agent thao tác trên tab, hệ thống tự động hiển thị viền màn hình phát sáng neon nhẹ nhàng (subtle glowing border) và khóa thao tác chuột/bàn phím để tránh xung đột mà không che chắn tầm nhìn:

  • Viền phát sáng cyberpunk nhẹ nhàng không làm mờ hay che khuất trang web
  • Tự động khóa thao tác chuột/bàn phím tạm thời khi Agent đang thực thi lệnh
  • Điều khiển ngầm mượt mà, tự động gắn tab vào nhóm 🤖 Agent Pilot
⚡

Quản Lý Service Ngầm & Đa Agent

Quản lý vòng đời dịch vụ chạy ngầm đa nền tảng và hỗ trợ nhiều AI Agent hoạt động đồng thời:

agent-pilot service install agent-pilot service status agent-pilot service restart agent-pilot service uninstall
  • Tự động cấu hình systemd --user (Linux), launchd (macOS), hoặc Task Scheduler (Windows)
  • Hỗ trợ bật đồng thời Antigravity, Codex, CLI đa nhiệm không xung đột cổng
  • Luôn truyền tabId để mỗi Agent làm việc độc lập trên tab riêng
🧪

Bộ Lệnh CLI Cho Tester / QC

Kỹ sư kiểm thử tự động có thể điều khiển trình duyệt trực tiếp qua terminal hoặc viết shell script kiểm thử tự động:

agent-pilot open "https://example.com" agent-pilot click "#login-button" agent-pilot type "#user" "admin" --enter agent-pilot screenshot -o page.png agent-pilot batch flow.json # Trusted CDP input (iframe khác origin / canvas / game WebGL) agent-pilot cdp status --tab 12345 agent-pilot click -x 733 -y 668 --via cdp --tab 12345 agent-pilot drag --from-x 745 --from-y 490 --to-x 745 --to-y 832 --hold 800 --via cdp --tab 12345 # Cài Agent Skill kèm binary agent-pilot skill install --agy --force

2. Lớp Lọc Bảo Mật & Che Giấu Secret / API Key

🔑

Tự Động Phát Hiện & Che Dấu Sao (*)

Bảo vệ tuyệt đối thông tin định danh của người dùng khỏi việc bị rò rỉ vào context log của các nhà cung cấp mô hình LLM AI (OpenAI, Google, Anthropic...).

  • Private Key: RSA, EC, OpenSSH, DSA, PGP Block
  • API Keys: OpenAI (sk-proj-), Anthropic (sk-ant-), Google Gemini (AIzaSy)
  • Cloud & Payment: AWS Access Key, Stripe, GitHub Token, Slack Token
  • Auth Tokens: JWT, Bearer header, URL query secret params
📢

Thông Báo Bảo Mật Cho AI Agent

Khi dữ liệu được lọc, extension tự động đính kèm đối tượng AGENT_SECURITY_NOTICE thông báo rõ ràng cho Agent biết các ký tự * là lớp che chắn bảo vệ, giúp Agent hiểu đúng logic mà không bị nhầm lẫn giá trị.

  • Báo cáo số lượng trường đã bị che giấu
  • Báo cáo danh mục loại secret được phát hiện
  • Bảo toàn nguyên vẹn cấu trúc JSON và kiểu dữ liệu
⚠️

Cảnh Báo Khi Người Dùng Tắt Lọc

Tính năng lọc được mặc định BẬT. Nếu người dùng muốn tắt trên Side Panel, một hộp thoại cảnh báo nguy cơ rủi ro bảo mật nghiêm trọng sẽ hiện ra yêu cầu xác nhận có chủ đích.

  • Tooltip giải thích ? gọn gàng, trực quan
  • Công tắc Toggle Switch kèm nhãn trạng thái thời gian thực
  • Đồng bộ hóa 2 chiều giữa Side Panel và Server MCP

3. Soi Phần Tử DOM & Thông Số CSS (Inspector Studio)

📌

Tab Tổng Quan (Overview)

Click nút "Bật Soi Phần tử" và rê chuột trên trang web. Khung viền xanh dương và tooltip thông minh bám theo phần tử DOM.

  • Tên thẻ HTML (<tag>) và Class name
  • Tọa độ X, Y và Kích thước Width × Height
  • CSS Selector và XPath tối ưu (hỗ trợ copy 1 chạm)
  • Xem trước nội dung văn bản (inner text) và giá trị input
  • Tự động tắt chế độ soi ngay khi đã click chọn xong phần tử
🎨

Tab Kiểu Dáng CSS (Computed CSS)

Hiển thị toàn bộ các thuộc tính CSS mà phần tử đang chịu ảnh hưởng thực tế trên trình duyệt, được phân nhóm khoa học theo chuẩn thiết kế web.

  • Typography: font-family, font-size, font-weight, color, line-height...
  • Layout: display, position, z-index, box-sizing, overflow...
  • Dimensions & Spacing: width, height, margin, padding...
  • Visuals: background-color, border, border-radius, box-shadow, opacity...
  • Flexbox & Grid: flex-direction, justify-content, align-items, gap...
  • Ô tìm kiếm lọc thuộc tính thời gian thực & nút 📋 Copy CSS toàn bộ
🎨

4. Công Cụ Kính Lúp Phóng Đại Lấy Mã Màu (Eyedropper)

🔍

Kính Lúp Phóng Đại 11×11 Pixel

Khi nhấp "🎨 Lấy mã màu", kính lúp tròn 132×132px viền neon sẽ xuất hiện bám sát theo con trỏ chuột của bạn trên trang web.

  • Phóng to 12× vùng 11×11 pixel quanh chuột giúp nhắm điểm cực kỳ chuẩn xác
  • Lưới pixel tinh tế kèm hồng tâm ngắm kép đen-xanh tương phản cao
  • Bảng màu nổi hiển thị trực tiếp mã HEX và RGB cạnh con trỏ chuột
  • Cơ chế tự động lật vị trí chống tràn ra ngoài mép màn hình
📌

Đa Định Dạng & Sao Chép 1 Chạm

Nhấp chuột vào điểm bất kỳ trên màn hình để trích xuất màu sắc:

  • Hỗ trợ trọn bộ 5 chuẩn mã màu: HEX, RGB, RGBA, HSL, OKLCH
  • Sao chép 1 chạm (1-Click Copy): Nhấp vào bất kỳ hàng mã màu nào hoặc biểu tượng 📋 để sao chép tức thì kèm Toast thông báo
  • Tự động lưu vào dải màu lịch sử (Palette History Chips) — nhấp chip màu để nạp lại cả 5 định dạng
  • Tự động sao chép mã HEX và tắt ngay chế độ nhặt màu để bạn tiếp tục duyệt web
  • Nhấn phím Esc để hủy bất kỳ lúc nào

Chụp Toàn Màn Hình & Cắt Vùng (Crop)

  • Hỗ trợ xuất định dạng PNG chuẩn chất lượng cao
  • Hiển thị kích thước pixel thực tế trên thẻ xem trước

Chụp Phần Tử Trực Tiếp Trên DOM

Nhấp nút "🎯 Chụp phần tử": trang web sẽ chuyển sang chế độ chọn phần tử bằng khung viền tím camera #a855f7 kèm tooltip hướng dẫn.

  • Không cần soi trước: Click vào bất kỳ phần tử nào trên trang để chụp ngay
  • Hiệu ứng chớp xanh xác nhận chụp thành công
  • Tự động tắt ngay chế độ chọn phần tử sau khi click chọn

Công Tắc Tự Động Sao Chép Vào Clipboard

Được tích hợp ngay dưới cụm nút chụp trong tab Chụp ảnh. Khi bật công tắc này:

  • Sẵn sàng nhấn Ctrl + V để dán ngay vào Figma, Slack, Discord, tài liệu...
  • Lưu trạng thái bật/tắt vào localStorage

6. Chú Thích & Chỉ Điểm Giao Diện Cho AI Agent (Visual UI Annotator)

🚀

Giải Pháp Cho Bài Toán Chỉ Điểm Vị Trí Cần Sửa Cho Coding Agent

Khi làm việc với AI Coding Agent, người dùng thường gặp khó khăn trong việc diễn đạt bằng lời chính xác vị trí lỗi hoặc component cần chỉnh sửa trên giao diện web. Tính năng Chú Thích & Chỉ Điểm UI (Visual UI Annotator) giải quyết triệt để bài toán này: người dùng trực tiếp khoanh vùng, chỉ chỗ và viết ghi chú trên trang web để giao cho AI Agent tìm đúng file nguồn framework (React Fiber, Vue, Astro:line) và tiến hành sửa code mà không sợ nhầm lẫn.

🎯

4 Chế Độ Thu Thập Phản Hồi Đa Điểm

  • Chọn phần tử (Element): Rà chuột bắt dính phần tử, tự động trích xuất tên Component, tệp nguồn (vd: src/components/Navbar.tsx:42) và cắt ảnh riêng phần tử đó.
  • Kéo chọn vùng (Region): Kéo thả chuột tự do trên màn hình để khoanh vùng bất kỳ khu vực lỗi nào.
  • Màn hình hiện tại (Screen): Chụp toàn bộ viewport và mở công cụ ghim điểm (Pins) đánh dấu nhiều vị trí trên cùng 1 ảnh.
  • Toàn trang (Full Page): Chụp toàn bộ trang web dài từ đầu đến cuối không bị che khuất.
  • Quản lý linh hoạt: Chế độ Chú thích duy trì liên tục trên trang web cho đến khi người dùng bấm Dừng Chú Thích (hoặc Thoát Chế Độ). Danh sách các vị trí đã chọn có thể sửa đổi ghi chú hoặc xóa bất kỳ lúc nào.
📡

3 Kênh Giao Tiếp Phản Hồi Độc Lập

  • Kênh A (Live Push & Long-Polling): Agent gọi công cụ browser_wait_for_feedback để tạm dừng chờ người dùng. Khi người dùng bấm "🚀 Gửi Agent", toàn bộ ảnh, vị trí code và ghi chú lập tức truyền trực tiếp về cho Agent.
  • Kênh B (Shared Inbox File System): Bấm "💾 Lưu Inbox" để lưu phiên phản hồi vào thư mục ~/.agent-pilot/inbox/feedback/<timestamp>/* (gồm session.json, prompt.md, và các ảnh item_*.png). Agent có thể đọc bất kỳ lúc nào bằng browser_get_pending_feedback.
  • Kênh C (1-Click Clipboard Prompt): Bấm "📋 Copy Prompt" để sao chép prompt định dạng Markdown hoàn chỉnh chứa toàn bộ ảnh, tệp nguồn component và yêu cầu chỉnh sửa vào Clipboard.
