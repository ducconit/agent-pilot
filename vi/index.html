Agent Pilot là sản phẩm được xây dựng 100% bằng hình thức "vibe coding" thông qua Google Antigravity. Toàn bộ thành phần—từ kiến trúc CLI Golang, Chrome Extension Manifest V3, MCP Server đến hệ thống tài liệu—đều do AI Agent tự động sinh mã, refactor và tối ưu hoá thông qua prompt engineering.

Vui lòng thử nghiệm trên profile Chrome riêng biệt (sandbox) hoặc môi trường non-production trước khi trao quyền điều khiển cho AI trên các tài khoản quan trọng.

Tác giả và cộng đồng đóng góp hoàn toàn không chịu trách nhiệm đối với bất kỳ sự cố mất mát dữ liệu, lỗi trình duyệt, thiệt hại tài chính hay hành động ngoài ý muốn nào do AI Agent gây ra trong quá trình vận hành.

🎯 Giới Thiệu, Mục Đích & Bộ Công Cụ Kiểm Thử, QA/QC, Debug Web ​

Agent Pilot ban đầu được xây dựng phục vụ nhu cầu cá nhân nhằm thay thế Chrome MCP mặc định trên Google Antigravity, đồng thời giải quyết triệt để sự bất tiện khi AI Agent phải tự sinh các đoạn code Python tạm bợ để thao tác trình duyệt hoặc vẽ chữ/khoanh vùng lên hình ảnh trong quá trình kiểm thử web.

Hiện tại, dự án hỗ trợ mọi công cụ AI điều khiển trình duyệt với tiêu chí cốt lõi: thao tác trình duyệt thuận tiện, tốn ít token nhất, tích hợp sẵn trọn bộ công cụ chuyên dụng phục vụ kiểm thử tự động (Web Testing), QA/QC và Debug ứng dụng web.

01 // TIẾT KIỆM TOKEN
Điều Khiển Thuận Tiện & Ít Token
Cây DOM tương tác được rút gọn thông minh (@1, @2) cùng cơ chế thực thi theo lô (Batch Execution), giúp tiết kiệm hơn 50% lượng token tiêu thụ trên cả Skills+CLI lẫn MCP.
02 // MINH CHỨNG QA/QC
Chụp Màn Hình & Ghi Chú Thích
Chụp khung nhìn hiện tại, chụp toàn trang (full-page) hoặc từng phần tử; hỗ trợ tự động khoanh vùng highlight phần tử lỗi và đóng dấu tiêu đề báo cáo kiểm thử.
03 // QUAY VIDEO
Ghi Video Luồng Kiểm Thử
Quay video trực tiếp quá trình tương tác, kiểm thử và tái hiện lỗi trên trình duyệt (kèm hiệu ứng chuột ảo neon và sóng click) để làm bằng chứng báo cáo trực quan.
04 // PLAYWRIGHT & REPLAY
Ghi Nhận, Replay & Xuất Playwright
Tự động ghi lại chuỗi thao tác thực tế trên trang, phát lại (replay) kịch bản kiểm thử bất kỳ lúc nào và xuất (export) trực tiếp ra mã nguồn kiểm thử Playwright chuẩn chỉnh.
05 // ĐO HIỆU NĂNG
Đo Performance & Lighthouse
Chạy kiểm định Lighthouse thực tế ngay từ dòng lệnh hoặc qua AI, đo lường các chỉ số Core Web Vitals (LCP, CLS, INP), phân tích performance trace và tốc độ tải tài nguyên.
06 // BẮT LỖI BỘ NHỚ
Tìm Memory Leak (V8 Heap Diff)
Chụp và đối chiếu chênh lệch giữa các bản chụp bộ nhớ V8 Heap trước/sau thao tác để phát hiện chính xác rò rỉ bộ nhớ, các node DOM bị treo hoặc sự kiện chưa giải phóng.
07 // DEBUG WEB
Bắt Lỗi Console, Network & DOM
Giám sát lỗi Console thời gian thực, lọc các truy vấn mạng thất bại (HTTP 4xx/5xx), soi thuộc tính CSS thực tế và tự động che giấu thông tin nhạy cảm (13 mẫu regex & 23 khóa thuộc tính).
08 // TRỰC QUAN & CÁCH LY
Feedback Studio & Chạy Ngầm
Ghim chú thích lỗi trực tiếp lên giao diện web, lấy mã màu pixel chuẩn xác để đẩy về AI; đồng thời gom tab tự động vào nhóm riêng không bao giờ cướp chuột của người dùng.

Cách 1: Cài Đặt Qua Bộ Cài Theo Hệ Điều Hành (Khuyên Dùng) ​

Đây là phương pháp cài đặt được khuyến nghị hàng đầu vì mỗi gói phát hành được đóng gói tối ưu riêng cho từng hệ điều hành, đảm bảo dung lượng nhẹ nhất và tích hợp trơn tru với các dịch vụ hệ thống của OS.

Bước 1: Tải Bản Phát Hành & Chạy Script Cài Đặt ​

Hệ Điều HànhGói Cài ĐặtLệnh Cài Đặt Tự ĐộngHướng Dẫn Chi Tiết
🐧 Linux / Ubuntuagent-pilot-*-linux.zip./install.shXem hướng dẫn Linux
🍎 macOSagent-pilot-*-macos.zip./install.shXem hướng dẫn macOS
🪟 Windowsagent-pilot-*-windows.zippowershell -ExecutionPolicy Bypass -File .\install.ps1Xem hướng dẫn Windows

Script cài đặt sẽ tự động sao chép file nhị phân vào thư mục PATH người dùng (~/.local/bin hoặc $env:LOCALAPPDATA\Programs\agent-pilot), đăng ký dịch vụ chạy ngầm tự khởi động cùng máy và giải nén thư mục tiện ích Chrome.

Kiểm tra trạng thái dịch vụ nền:

bash
agent-pilot service status

Bước 2: Nạp Extension vào Chrome ​

  1. Mở Chrome, truy cập chrome://extensions.
  2. Bật công tắc Developer mode ở góc trên bên phải.
  3. Nhấp Load unpacked ở góc trên bên trái và chọn thư mục extensions/ vừa giải nén.
  4. Ghim biểu tượng Agent Pilot (📌) lên thanh công cụ Chrome.

Cách 2: Cài Đặt Nhanh Cho AI Agent (npx skills add) ​

Nếu bạn muốn trang bị nhanh kỹ năng điều khiển trình duyệt cho AI Agent mà không cần tải thủ công các tệp nén release, hãy sử dụng lệnh từ hệ sinh thái skills.sh:

bash
npx skills add https://github.com/ducconit/agent-pilot -g --all

💡 Lưu ý về phương án cài nhanh: Phương thức này được thiết kế để bootstrap nhanh cho AI Agent trên bất kỳ máy tính nào. Vì tính chất đa nền tảng, gói kỹ năng này chứa sẵn các file nhị phân biên dịch cho cả 3 hệ điều hành (Linux agent-pilot, macOS agent-pilot, Windows agent-pilot.exe) nằm trong thư mục skills/agent-pilot/scripts/. Nếu muốn cài đặt tinh gọn, tối ưu dung lượng và tự động đăng ký daemon hệ thống cho máy của bạn, hãy ưu tiên dùng Cách 1 (Bộ cài đặt theo hệ điều hành).

Để nạp tiện ích vào Chrome, bạn chỉ cần mở thư mục kỹ năng vừa cài hoặc tải thư mục extensions/ rồi nạp qua chrome://extensions (Load unpacked).

Cách 3: Tự Biên Dịch & Cài Đặt Từ Mã Nguồn (Dành Cho Nhà Phát Triển) ​

Dành cho lập trình viên muốn nghiên cứu, tùy biến backend Go hoặc kiểm thử các tính năng mới của Chrome extension:

  1. Sao chép (clone) kho mã nguồn:

    bash
    git clone https://github.com/ducconit/agent-pilot.git
cd agent-pilot

  2. Biên dịch file nhị phân Go CLI:

    bash
    go build -o bin/agent-pilot ./cli/cmd/agent-pilot

  3. Cài đặt dịch vụ chạy ngầm:

    bash
    ./bin/agent-pilot service install
./bin/agent-pilot service status

  4. Nạp tiện ích mở rộng vào Chrome: Mở Chrome → chrome://extensions → Bật Developer mode → Nhấn Load unpacked → Chọn thư mục extensions/ trong repository.

🤖 Kết Nối Với Mọi Trợ Lý AI Coding ​

Sau khi cài đặt, Agent Pilot tương thích đa năng với mọi trợ lý AI coding hoặc công cụ tự động hóa qua Agent Skills + Command Line (CLI) hoặc Model Context Protocol (MCP):

Cách A: Dùng Agent Skills + Command Line (CLI) ​

Hoạt động tức thì với Claude Code, Cursor, Windsurf, Google Antigravity, Cline / Roo Code, OpenCode, Codex, Aider, hoặc bất kỳ agent nào có quyền thực thi lệnh terminal:

bash
# Cài đặt qua hệ sinh thái skills.sh
npx skills add https://github.com/ducconit/agent-pilot -g --all

# Hoặc cài trực tiếp bằng CLI độc lập
agent-pilot install-skill --all

Cách B: Cấu Hình MCP Server (mcp.json) ​

Tương thích với mọi MCP Client (Claude Desktop, Claude Code, Cursor, Windsurf, Google Antigravity, Zed, Continue, v.v.):

json
{
  "mcpServers": {
    "agent-pilot": {
      "command": "agent-pilot",
      "args": ["mcp"]
    }
  }
}
